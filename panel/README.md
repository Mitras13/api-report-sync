# مدار — پنل محلی عملیات داده

از ریشهٔ پروژه اجرا کنید:

```powershell
python -m panel.server
```

یا `start_panel.cmd` را باز کنید. آدرس: http://127.0.0.1:8876

پنل با Python و وابستگی‌های فعلی پروژه اجرا می‌شود. اتصال SQL از همان تنظیمات `load_raw_data_to_sql.py` و هویت ویندوز استفاده می‌کند. سرور فقط روی loopback گوش می‌دهد؛ برای انتشار شبکه‌ای طراحی نشده است. اجرای پنل، دانلود یا تغییر SQL را خودکار شروع نمی‌کند.

- نمای کلی: شمارش تقریبی رکوردها از متادیتای SQL، وضعیت اتصال و فضای آزاد دیسک.
- پوشش و ریپلیس: پوشش روزانهٔ شمسی از اولین فایل مشاهده‌شده تا امروز، تا سقف ۵۰۰۰ روز؛ نمای کلی ۳۵ روز اخیر را نشان می‌دهد. جزئیات گزارش تمام این روزها را نمایش می‌دهد.
- سبز تیره: فایل روز در SQL ثبت شده و نسخهٔ قدیمی در `_retired_raw` مشاهده شده است. این وضعیت به معنی بازخوانی موفق در اجرای اخیر نیست؛ تاریخ آخرین دریافت در جزئیات روز وجود دارد.
- فاقد فایل: نبود فایل، الزاماً خطا یا وجود داده در مبدأ را اثبات نمی‌کند. پیش از اولین تاریخ مشاهده‌شده، پوشش تاریخی قابل اثبات نیست.
- قطع SQL: وضعیت ورود فایل‌ها نامشخص است؛ فایل خام همچنان قابل رصد است.
- توکن‌ها: بررسی محلی انقضا و بررسی آنلاین اختیاری برای چهار توکن؛ خطای شبکه به‌صورت نامشخص نمایش داده می‌شود. مقادیر توکن به مرورگر فرستاده نمی‌شوند. تمدید تعاملی OTP همچنان با ابزار موجود پروژه انجام می‌شود.
- تنظیمات: فعال/غیرفعال کردن دانلودر، پنجرهٔ ریپلیس ۰ تا ۹۰ روز و فاصلهٔ درخواست‌ها. ذخیره اتمیک است و از اجرای بعدی `main.py`، از جمله اجرای Task Scheduler، اعمال می‌شود. تغییرات روی اجرای در حال انجام اثر ندارد.
- پنجرهٔ ریپلیس یعنی تعداد روزهای اخیر برای بازخوانی در هر اجرا، نه دورهٔ زمان‌بندی. زمان‌بندی خودکار موجود ویندوز عوض نمی‌شود.
- اجرای دستی همان `main.py` را با قفل موجود پروژه اجرا می‌کند. بستن پنل اجرای شروع‌شده را لغو نمی‌کند.
- سلامت/ظرفیت: آمار جدول و فضای فایل؛ جایگزین DBCC CHECKDB یا بررسی fragmentation نیست. پنل هیچ عملیات بهینه‌سازی مخرب یا تغییر ساختار SQL انجام نمی‌دهد.

وضعیت ۳۰ ثانیه کش می‌شود. گزارش فعال از قفل فرایند و رویدادهای `logs/robot_downloader.log` قابل مشاهده است. `panel/settings.json` تنظیمات محلی است و وارد Git نمی‌شود.

طراحی: فارسی، راست‌به‌چپ، رنگ‌های خنثی و سبز، با الگوی نمای کلی ← جزئیات و کاهش شلوغی از [راهنمای Grafana](https://grafana.com/docs/grafana/latest/visualizations/dashboards/build-dashboards/best-practices/).

## Shared authenticated dashboard (2026-11-03)

The panel is now available inside http://127.0.0.1:8770/database (Robot_Reward). Start Robot_Reward/main.bat first. The standalone port 8876 redirects to the shared dashboard and rejects legacy write requests. The shared panel uses a private subprocess bridge; no separate unauthenticated backend HTTP port is required. Existing settings, reports and manual actions remain available after administrator login.
